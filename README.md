# Roger Corso Arquitetura e Interiores

Página estática em formato de painel/apresentação comercial premium.

## Como visualizar

Abra `index.html` no navegador. A apresentação tem 5 seções, navegação fixa, CTAs clicáveis e CSS de impressão para exportar em PDF pelo próprio navegador.

## Arquivos

- `index.html`: apresentação completa, tokens visuais, conteúdo e comportamento de navegação.
- `README.md`: instruções rápidas de uso.
